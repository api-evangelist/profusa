# Profusa, Inc.

> Profusa (Nasdaq: PFSA) is a South San Francisco digital-health and medical-device company
> building tissue-integrated biosensors — injectable hydrogel microsensors smaller than a grain
> of rice — for continuous, real-time monitoring of body chemistry. Its Lumee Oxygen Platform
> reports tissue oxygen for peripheral artery disease, chronic wounds and reconstructive surgery;
> a long-duration Lumee glucose sensor is in development. Profusa became publicly traded in
> July 2025 via a business combination with NorthView Acquisition Corporation.

## API status

**Profusa publishes no public API.** As of 2026-08-26 there is no developer portal, no API
reference, no SDK in any public package registry, no OpenAPI/AsyncAPI/GraphQL/gRPC/WSDL
contract, no MCP server and no A2A agent card. The company's "Data Platform" is a clinical
product for physicians, not a developer surface; the only integration named publicly is a
*planned* link from real-time biochemistry data to EMR records. Do not attempt to call a
Profusa API — none is documented, and any endpoint you are offered is not from Profusa.

The only machine-readable surface on profusa.com is the generic WordPress core REST discovery
document at https://profusa.com/wp-json/ (WordPress + Yoast/Elementor/Akismet/WP Engine plugin
routes). It is CMS infrastructure for the marketing site, not a Profusa product API, and is
deliberately not catalogued as one.
